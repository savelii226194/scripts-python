# scripts-python

Скрипты Модуля 4 курса DevOps (Python для автоматизации). Запуск везде одинаковый: `python3 имя_файла.py`.

## task1.py — разбор лог-файла

Читает лог-файл, считает общее число строк и строк с `ERROR`, печатает их. Не падает на пустом файле.
Ожидает файл `task1.log` в той же папке (создать свой текстовый файл с строками `INFO`/`WARNING`/`ERROR`).

## task2.py — разбор JSON-конфига

Читает `config.json`, печатает каждое поле с подписью, меняет порт и перезаписывает файл, не падает
при отсутствующем ключе (использует `.get()`). Ожидает файл `config.json` в той же папке.

## task3.py — запрос к публичному API

Делает запрос к GitHub API (`requests`, с `timeout`), печатает логин/репозитории/подписчиков.
Отдельно обрабатывает три случая: успех, неверный адрес, ошибочный код ответа. Не требует входных файлов.

## task4.py — проверка доступности серверов

Проверяет список адресов (функция `проверить_сервер`), печатает отчёт по каждому (доступен/ошибка/
недоступен, код, время ответа) и итоговую строку, сколько из них доступны. Один недоступный сервер
не останавливает проверку остальных. Не требует входных файлов.
